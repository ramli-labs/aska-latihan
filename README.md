# Latihan ASKA Praktik Informatika – Kelas IX

Web latihan (drilling) ujian praktik Python kelas IX SMP Labschool Jakarta.

- Login: pilih kelas → pilih nama (daftar dari Google Sheet).
- Drill per jenis soal (1–6), angka dan konteks acak, cek otomatis dengan data uji.
- Petunjuk, materi bacaan, dan pembahasan (terbuka setelah Cek Jawaban).
- Aktivitas latihan tercatat ke Google Sheet (tab Log & Rekap).
- Python berjalan di browser (Pyodide), tanpa instalasi.

File: `index.html`, `soal.js` (generator soal), `materi.js` (bahan bacaan), `worker.js` (Python), `apps-script/Code.gs` (backend).
Daftar nama murid **tidak** disimpan di repo ini; nama ada di Google Sheet milik guru.
